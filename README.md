Pakistani Tourism - Front-End Web Project
A functional five-page website designed to promote tourism across Pakistan. This project serves as a front-end prototype showcasing the use of HTML, CSS, and basic JavaScript integration.

Project Overview
The Pakistani Tourism website provides an informative platform for travelers. It features a universal navigation system, detailed destination highlights, and an interactive booking feedback system.

Features
Five Connected Pages: Includes Home, About Us, Packages, Destination, and Contact Us.

Global Navigation Bar: A persistent menu on every page allowing for non-linear navigation.

Interactive Logic: Internal JavaScript on the Packages page that triggers a "Booked!" alert when a user clicks a booking button.

Custom Visuals: The project utilizes high-quality images generated via Gemini AI to represent various Pakistani landscapes.
